# 量化策略研发全流程 Checklist

> 基于「外层WF + 内层CPCV」嵌套架构，覆盖数据划分→内层调参→外层盲测→敏感性分析→蒙特卡洛验证的完整链条。每次策略迭代前逐项对照，杜绝无意识泄露与过拟合。

---

## 一、数据划分阶段

### 1.1 原始数据清洗
- [ ] 确认数据时间范围覆盖完整的牛/熊/震荡周期（建议≥8年）
- [ ] 检查缺失值、异常值、复权处理是否正确
- [ ] 确认数据频率（日线/小时线/分钟线）与策略逻辑匹配
- [ ] 确认无前视偏差（Look-Ahead Bias）：财报数据使用公布日期而非报告期

### 1.2 外层WF窗口划分
- [ ] 确定WF滚动窗口的数量与长度（如10折，每折2年）
- [ ] 明确每折的 IS（训练集）和 OOS（测试集）划分边界
- [ ] 确认OOS测试集在整个研发周期内**绝对封存**，不参与任何参数选择决策
- [ ] 记录每折的起止日期，便于后续审计追溯

### 1.3 内层CPCV子集划分
- [ ] 确定CPCV的子集数量S（建议S≥16，偶数）
- [ ] 确认框架已启用 **Purge（净化）** 参数：剔除标签生成与验证集重叠的训练样本
- [ ] 确认框架已启用 **Embargo（禁运）** 参数：在验证集后设置时间间隔切断自相关泄漏
- [ ] 记录Purge和Embargo的具体步数/天数设置

---

## 二、内层CPCV调参阶段

### 2.1 目标函数与评价指标
- [ ] 明确内层CPCV的优化目标函数（如 dsR 缩减夏普比率）
- [ ] 确认评价指标在CPCV多条路径上均有计算
- [ ] 记录每条路径的 dsR 值及路径均值、方差
- [ ] 确认目标函数**未**使用OOS数据的信息

### 2.2 网格搜索执行
- [ ] 明确参数空间的搜索范围与粒度
- [ ] 确认每组参数组合在CPCV的**所有路径**上完成回测
- [ ] 记录每组参数的各路径 dsR 及综合指标（如路径均值）
- [ ] 确认搜索过程仅依赖CPCV验证集，未触碰外层OOS

### 2.3 候选参数筛选
- [ ] 选出内层CPCV综合指标最优的Top-K参数组合（建议K=3~5）
- [ ] 检查Top参数的 dsR 是否显著优于随机参数基线
- [ ] 记录候选参数的具体数值及对应指标

---

## 三、外层WF盲测阶段

### 3.1 候选参数外测
- [ ] 将内层选出的每个候选参数组合，分别执行完整的外层WF流程
- [ ] 记录每折OOS片段的净值曲线、收益率、回撤等指标
- [ ] 拼接所有OOS片段，计算综合样本外评价指标
- [ ] 选出外层WF综合表现最优的参数组合

### 3.2 外测结果审计
- [ ] 对比内层CPCV指标与外层WF OOS指标的衰减比（WFE = OOS夏普 / IS夏普）
- [ ] 确认WFE > 0.5（策略具有稳健泛化能力）
- [ ] 检查OOS净值曲线是否存在异常陡升（可能暗示过拟合）
- [ ] **一旦根据外测结果调整策略，该OOS数据永久作废，需获取全新数据重测**

---

## 四、参数敏感性分析阶段

### 4.1 单参数敏感性测试
- [ ] 以外层最优参数为基准，逐个参数进行 ±10%~±30% 扰动
- [ ] 记录每个扰动方向上的净值曲线变化
- [ ] 观察绩效衰减：参数微小变动是否导致收益波动 > 50% 或夏普大幅下降
- [ ] 观察交易行为一致性：扰动后交易频率/持仓分布是否剧变
- [ ] 绘制单参数敏感性曲线图，确认是否存在"参数高原"

### 4.2 多参数联合敏感性（热力图）
- [ ] 选取2个核心参数进行联合网格扰动
- [ ] 生成参数敏感性热力图（Heatmap）
- [ ] 识别大面积绩效稳定的"最优区域"（参数高原）
- [ ] 避开仅在极小区域发亮的"参数孤岛"

### 4.3 消融实验（Ablation Study）
- [ ] 固定最优参数，逐个关闭策略中的逻辑模块（如过滤条件、止损规则等）
- [ ] 对比关闭前后的绩效差异，评估各模块的边际贡献
- [ ] 确认每个模块都有正向贡献，剔除无效模块
- [ ] 可选：执行累积添加法（Baseline → +A → +A+B → ...），验证各组件增量价值

---

## 五、蒙特卡洛验证阶段

### 5.1 参数随机扰动模拟
- [ ] 对最优参数进行大量随机扰动（建议≥500次）
- [ ] 每次扰动后执行完整回测（CPCV或WF框架）
- [ ] 统计正收益概率（要求 > 80%）
- [ ] 统计收益分布的均值、中位数、标准差、分位数

### 5.2 时间延迟扰动（Time Lag Perturbation）
- [ ] 随机延迟入场时机（如延迟1~3根K线）
- [ ] 观察策略对入场时机的敏感程度
- [ ] 确认策略不因微小的时间错位而失效

### 5.3 结果判定
- [ ] 蒙特卡洛正收益概率 ≥ 80% → 通过
- [ ] 蒙特卡洛收益中位数 > 0 → 通过
- [ ] 95%分位数收益 > 0 → 通过（极端情况也不亏）
- [ ] 以上条件全部满足 → 策略进入实盘模拟阶段
- [ ] 任一条件不满足 → 返回内层调参或重新审视策略逻辑

---

## 六、最终交付前检查

### 6.1 文档与可复现性
- [ ] 策略逻辑文档化（经济学/微观结构解释清晰）
- [ ] 目标函数、参数范围、停止规则预注册（Pre-registration）
- [ ] 所有代码版本控制（Git提交记录完整）
- [ ] 回测结果可复现（固定随机种子）

### 6.2 风控底线
- [ ] 最大回撤在可承受范围内
- [ ] 压力测试（极端行情）下未出现毁灭性亏损
- [ ] 交易成本（手续费、滑点）已充分计入
- [ ] 策略容量评估完成（不影响市场微观结构）

### 6.3 最终决策
- [ ] PBO（回测过拟合概率）< 0.3（如已执行）
- [ ] 参数高原检验通过（参数扰动后绩效稳定）
- [ ] 蒙特卡洛验证通过
- [ ] 策略逻辑经得起"经济学直觉"检验
- [ ] **以上全部通过 → 可进入实盘模拟（Paper Trading）**

## 附：关键原则速记

| 原则 | 说明 |
|------|------|
| OOS封印原则 | 外层OOS测试集一旦使用即不可再用于调参，污染即作废 |
| 一发子弹原则 | 外层OOS只允许一次最终评估，不可反复试探 |
| 参数高原原则 | 优选参数高原区域，放弃参数孤岛极值点 |
| 奥卡姆剃刀 | 参数越少越好，能用简单逻辑解决的不用复杂模型 |
| 逻辑先行 | 策略逻辑必须先于回测结果成立，不可因曲线好看而修改目标函数 |
| 消融验证 | 每个模块必须有正向边际贡献，否则剔除 |
